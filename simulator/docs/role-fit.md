[공식 공고](https://wonik.recruiter.co.kr/career/jobs/128767)의 원익홀딩스 경영지원 인사는 HR Data & AI 활용 방안 기획을 모집한다. HR 전반의 AI·데이터 과제 발굴, LLM·생성형 AI·자동화 솔루션 도입·관리, 채용·퇴사율·성과 데이터 수집·정제·분석·DB 구축이 핵심이다. 이 프로젝트는 그중 교육 분야의 과제 발굴과 합성 역량 데이터 품질·비교·검증에 연결한다. 실제 HR 경력의 대체물로 제시하지 않는다.

## 3. 중간 설계 판단

**주제 선정:** 생산 병목만 보여주면 HR 직무 연결이 약하다. 자동화 이후 검사 역량 공백과 교육 후보를 함께 비교하는 질문으로 좁혔다.

**데이터 구현:** 완전 합성 역량 원장 4행에서 ID 중복, 스킬/자격 결측·타입, 교육 적격성을 검수한다. 검사 가능 인원 1→2명, 교육 후보 1명·8시간을 집계하고 원본 SHA-256·스냅샷을 SQLite 실험행에 저장한다. 오류 행을 자동 보정하지 않는다. 실제 직원 이력·개인 평가·채용 순위는 없다.

**AI 구현:** Qwen2.5-1.5B-Instruct 실제 CPU float32 forward가 미리 정의한 기준/로봇/교육/결합 중 선호를 선택한다. 수요·금지 조건은 명시적 파서, 수치 결과는 실제 SimPy가 계산한다. 자유 JSON 생성·기업 문서 검색·로봇 자율제어는 구현하지 않았다.

**검증:** 24개 백엔드 테스트, 세 단계의 종료 화면 재생 검사, 9건 실제 의미해석/4건 파서 거절, 실제 LLM HTTP 계획→실험→재조회·SQLite 재연결 동일성을 확인했다. 초기에 실패한 0.5B 5/9 결과도 보존한다. 고정 평가 통과율은 운영 정확도가 아니다.

## 4. 지원 시 설명할 가치와 한계

AI 과제를 실제 실행 흐름으로 만들고, 데이터 품질·LLM 선택·계산·저장 오류를 분리해 확인한 개인 PoC로 설명한다. 생산성 수치는 합성 조건의 완료 수량이며 실제 사업 성과가 아니다. 교육 8시간 후 검사 자격 취득은 가정이다. 도입비·ROI·안전·실제 교육 효과·자동화 예외 대응 인력은 미검증이다. 전체 작업자 4명 유지라는 모델 가정과 실제 인사 인력 최적화를 혼동하지 않는다.

포트폴리오에는 ① 움직이는 공장과 문제 ② 실제 LLM·계산·DB 모식도 ③ 비교·실패·검증을 담는다. 실제 HR 실무 경험이나 원익의 실제 공장 구현으로 확대하지 않는다.
