# 재사용과 이번 구현

공고의 교육 분야 AI 과제 발굴·LLM 자동화 운영·HR 데이터 정제 업무를 위해 교육 요청·현행 근거 검토·승인 원장을 만들었습니다.

원본은 창신 Lean 세션의 `new-chat-2/outputs/line-lens-public`입니다. 원본 절대 경로·초기 SHA256은 작업용 `work/wonik-runtime/source-manifest.json`에 보관했습니다. 원본을 수정하지 않고 별도 복사본을 확장했습니다.

| 재사용 | 이번 변경/신규 |
|---|---|
| Three.js·공정 선택·카메라·배속·재생 | 부품 트레이·일반 조립 공정 이름·합성 경고 |
| 같은 시드의 생산·품질·인력·속도·휴식 계산 | 읽기 전용 교육 참고 요약. 원래 수치 계수 유지 |
| llama.cpp 목표 해석·허용 후보 ID/근거 검증 | 교육 문서·과정 JSON Schema 선택·규정 검증 |
| 원본 공정·분석 회귀 | 합성 원장 정규화·검색·승인/거절·중복 방지·저장 |

Codex로 구현·통합·검증한 개인 데모입니다. 재사용한 기능을 새로 처음 만들었다거나 원익에서 운영한 경력으로 주장하지 않습니다.

교육 승인은 계획만 확정합니다. 공정 효과·이수·자격을 부여하지 않습니다. 검색은 정확한 키워드 기반이며 임베딩/벡터 검색은 없습니다. 규정 충돌은 같은 키의 복수 현행 문서 시나리오를 감지하며 임의 자연어 전체의 논리 모순 탐지가 아닙니다. n8n JSON은 미실행 템플릿입니다.

공식 ATS는 HR Data & AI 업무를 뒷받침합니다. 원익로보틱스 디지털 트윈은 계열사 사업 배경입니다. 실제 LMS·HR DB·SOP·교육 성과·내부 AI 프로젝트·n8n 사용 여부는 미확인입니다. X 참고는 이번 접근 제한으로 영상 전체를 재검증하지 못했고 회사 수요의 증거로 쓰지 않았습니다. 직접 확인한 창신 실행 프레임을 활용했습니다.

전체 자동 테스트49개는 기존39개+신규교육/UI10개입니다. 실제 모델과 브라우저 관측은 evidence/live-validation.json에 따로 기록합니다.
