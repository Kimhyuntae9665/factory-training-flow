# 재사용·기여·검증 범위

공고의 교육 분야 AI 과제 발굴·LLM 자동화 운영·HR 데이터 정제 업무를 위해 교육 요청·현행 근거 검토·선택 방식 비교·교육계획 원장을 만들었습니다.

원본은 창신 Lean 세션의 `new-chat-2/outputs/line-lens-public`입니다. 원본 절대 경로와 초기 SHA256은 작업용 `work/wonik-runtime/source-manifest.json`에 기록했습니다. 원본을 수정하지 않고 별도 복사본을 확장했습니다.

| 재사용 | 이번 구현·변경 |
|---|---|
| Three.js, 공정 선택·카메라·재생 | 부품 트레이·일반 조립 공정 이름·합성 경고 |
| 같은 시드의 생산·품질·인력·속도·휴식 계산 | 교육 화면의 읽기 전용 공정 참고 요약. 교육효과와 별도 |
| llama.cpp와 허용 ID·근거 검증 방식 | 교육 전용 schema와 코드 검증 |
| 기존 공정·분석 회귀 | 합성 CSV 정규화, rules/llm 비교, 보류·승인·거절·멱등 저장, 입력 변경 UI 회귀 |
| 기존 실행 화면 | n8n webhook·Wait·결정·JSON/CSV 연계 및 실행 증거 뷰어 |

사용자가 프로젝트 방향·화면·설명을 검토하고 Codex가 구현·계산 검증을 지원한 개인 데모입니다. 재사용 기능을 처음부터 만든 결과나 원익에서 운영한 경력으로 표현하지 않습니다. 기존 `analysis/`는 원본 CSV 분석·회귀를 보존한 자료이며 신규 HR 기능으로 설명하지 않습니다.

## 교육 검토의 실제 범위

규칙 방식은 현행 문서의 정확 키워드와 수강 조건을 대조합니다. 과정 하나만 남으면 모델 없이 선택하고 여러 과정이면 다시 묻습니다. LLM 방식은 전체 현행 문서 7개와 수강 가능한 과정 enum으로 자연어 요청을 해석하며 `select`·`clarify`·`no_match`를 반환할 수 있습니다. 임베딩·벡터 검색은 없습니다.

선수 자격·기이수·필수 근거·현행 상태는 코드가 선택 전후에 확인합니다. 고정 설명은 코드 검증 결과입니다. 이 검증을 통과해도 모델의 의미 선택이 틀릴 수 있으므로 최종 담당자 검토가 필요합니다. 규정 충돌 검사는 같은 키의 복수 현행 문서 감지이며 자연어 규정 전체의 논리 모순 탐지가 아닙니다.

교육 승인은 계획만 확정합니다. 교육 이수·자격 취득·생산량 효과를 부여하지 않습니다. `.learning-state.json`은 DB가 아닌 파일 원장이며 단일 앱 프로세스 안에서만 잠금을 사용합니다. 선택 방식·모델 ID·근거를 기록하고 중복 승인을 방지합니다.

## 검증의 의미와 한계

[비교 결과](../evidence/comparison-20261010-final/results.json)는 개발자가 라벨을 작성한 합성 요청 20개를 두 방식으로 실행하는 소규모 시연 평가입니다. `completedAt`·`summary`·개별 응답·코드/자료/문항 해시로 완결성과 오류를 확인합니다. 개발자 라벨을 사용하며 독립 홀드아웃은 없습니다. 규칙 기준선은 고정 키워드 구현으로 최적화한 규칙 전체를 대표하지 않으며 일반 정확도 차이로 확대하지 않습니다. 의미 선택 정답과 코드 근거 검증 통과를 별도로 읽습니다. 초기 준비 실패·예비 실행과 최종 결과도 구분합니다.

완료된 비교에서 규칙은 12/20, LLM은 15/20 라벨과 일치했습니다. 선택 근거 오류는 0건이었으나 LLM 의미 오답은 5건입니다. 특히 자격 부족 요청에 다른 허용 과정을 제안한 E16·E17은 코드 검증의 한계를 보여 주므로 자동 승인 근거로 쓰지 않습니다.

[n8n 실행 증거](../evidence/n8n-20261010.json)는 해당 워크플로의 실행 ID·Wait·결정·계획 JSON·CSV를 연결해 검증하는 자료입니다. 검증 스크립트가 보낸 승인·거절은 명시적인 합성 테스트 POST이며 담당자의 실제 클릭이 아닙니다. 실행 증거 뷰어는 자체 작성 화면으로 n8n 편집기 UI가 아닙니다. n8n의 실행 DB와 앱의 교육계획 파일 원장도 서로 다른 저장소입니다.

Mock 회귀는 구조·근거·자격·보류·멱등성·저장·비동기 UI 상태를 확인합니다. 실제 모델의 의미 선택·응답시간 또는 실제 브라우저 가독성을 보장하지 않습니다. [기존 브라우저 관측](../evidence/live-validation.json)은 기록 당시의 화면·합성 공정 결과이며 교육 효과나 회사 실적이 아닙니다. 최신 지원 자료는 [3페이지 v3 PDF](../../김현태_원익홀딩스_LearningLens_v3.pdf)입니다.

## 회사 자료와 구분

[원익그룹 공식 ATS](https://wonik.recruiter.co.kr/career/jobs/128767)는 제작 대상 HR Data & AI 업무의 근거이며 확인 기록은 2026-10-09 기준입니다. [원익로보틱스 디지털 트윈](https://wonikrobotics.com/kr/sub/application/robotAutomation/digital_twin.php)은 계열사 사업 배경입니다. 해당 HR 조직의 내부 추진 과제나 실제 사용 도구를 확인한 자료는 아닙니다.

공정·작업자·SOP·교육과정은 합성입니다. 실제 공장을 연결·보정한 디지털 트윈, 실제 LMS·HR DB·내부 SOP·교육성과·n8n 운영은 미확인입니다. X 참고 영상은 접근 제한으로 전체를 재검증하지 못했으며 회사 수요의 증거로 사용하지 않았습니다. 로컬 연결의 동작과 사내 권한·인증·개인정보 처리·운영 배포는 구분합니다.
