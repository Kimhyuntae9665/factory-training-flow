## 1페이지 · 교육 AI 과제 발굴

공고의 교육 분야 AI 과제 발굴 업무를 위해, 합성 작업자의 검사 역량과 교육 대안을 비교·검토하는 데모를 만들었습니다.

합성 작업자 4명의 검사 역량을 검수하고 자동화·교육 대안을 비교합니다. AI 도구를 활용해 n8n 워크플로, Python 연결부, 검토 화면을 구현했으며 사람이 승인한 경우에만 교육 계획을 저장하도록 구성했습니다.

원익로보틱스의 공개 디지털트윈 사례를 문제 배경으로 참고했습니다. 실제 직원·원익 내부 데이터나 HR 실무 성과가 아니며 원익의 n8n 사용 여부와 현장 비용·안전·교육 효과는 미확인입니다.

## 2페이지 · LLM과 업무 자동화 연결

공고의 LLM·생성형 AI·RPA 솔루션 도입·운영 업무를 위해, 실제 Qwen의 대안 선택·SimPy 비교와 n8n 승인 대기를 연결한 업무 흐름을 만들었습니다.

n8n은 요청 접수와 분기, 검토 대기, 결정 후 실행을 연결합니다. 실제 Qwen2.5-1.5B-Instruct는 사전에 정한 4개 대안의 라벨 점수로 요청의 선호를 선택하고 SimPy는 같은 주문과 10개 seed로 공정 수치를 계산합니다.

LLM이 수치나 설비 설정을 자유 생성하지 않습니다. 비교 설명은 계산값으로 작성한 정형 요약입니다. 교육 적격 후보 1명에게 사전교육 8시간 후 검사 자격이 생긴다는 가정을 두었으며 실제 교육 효과는 확인하지 않았습니다.

완료된 기록은 재시작 후에도 조회합니다. 승인 통신 실패에는 같은 결정을 재전송할 수 있고 확정 호출은 5회까지 재시도합니다. 그 뒤에도 실패한 n8n 실행은 운영자가 원인을 해결하고 재시도해야 합니다.

## 3페이지 · 입력 검수와 승인 근거 보관

공고의 데이터 수집·정제·데이터베이스화 업무를 위해, 합성 역량 입력을 검수하고 승인 근거를 SQLite에 남기는 흐름을 만들었습니다.

승인 전에는 교육 계획이 없고 승인하면 1건을 저장하며 거절하면 0건을 유지합니다. 결측 입력은 모델 호출 전에 차단합니다. 중복 요청과 같은 결정의 재전송은 기록을 늘리지 않고 다른 결정으로 바꾸려는 요청은 거절합니다.

n8n 2.42.3에서 승인·거절·결측 3개 경로를 실행했고 실제 Qwen 호출은 2건입니다. 연결부 단위 테스트 21건은 모델 선택을 mock으로 확인했습니다. 완료 수량 36.1·36.9·43.6·58.3개는 합성 공정을 10개 seed로 계산한 평균입니다.
